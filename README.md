# A_6
ESP32-based smart automation PCB with 6 relays, Ethernet, RS485, and LoRa connectivity. Supports both wired and wireless control for industrial or home automation. Ideal for IoT projects requiring remote monitoring, reliable communication, and integration with various sensors and smart systems.
